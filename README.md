# Reformation Map Challenge: Europe, 1560

An interactive, self-checking classroom activity for identifying the dominant religious traditions of Europe in 1560.

## Student experience

- Explore mode introduces 13 representative regions.
- Challenge mode randomizes the regions and records first-try accuracy.
- Immediate feedback explains each classification.
- Categories include Roman Catholic, Anglican, Calvinist, and Lutheran.
- Mixed regions and religious minorities are explicitly acknowledged.

## Run locally

Download the repository and open `index.html` in a modern web browser. No installation, account, server, or internet connection is required.

## Files

- `index.html` - page structure
- `styles.css` - responsive visual design
- `app.js` - interactive map logic and assessment flow
- `reformation-map-1560.png` - classroom source-map image
- `OFFLINE-README.txt` - short offline-use directions

## Classroom note

The activity uses the phrase **dominant religion**. It does not imply that every resident of a region shared the same belief. Hatched and mixed areas on the source map represent important historical complexity.

The supplied classroom map image remains subject to its original rights and is not relicensed by this repository.

REFORMATION MAP CHALLENGE - OFFLINE USE

1. Keep index.html, styles.css, app.js, and the assets folder together.
2. Double-click index.html to open the activity in a web browser.
3. No internet connection, account, or installation is required.

The Explore mode teaches the dominant tradition associated with each marker.
The Challenge mode randomizes all 13 regions and records first-try accuracy.

Classroom note: The activity follows the categories visible on the supplied
1560 source map. It describes dominant traditions; it does not imply that
every person within a region shared the same religion.
